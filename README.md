# ITAI_ML_FirstRepo_Kurt

My first GitHub repository, created for the **ITAI Classic Machine Learning** course.

## About

This repository was set up as an introduction to GitHub: creating a repository,
adding files, working on a branch, and merging changes through a pull request.
It is the foundation for submitting and collaborating on machine learning
projects throughout the course.

## Contents

| File | Description |
|------|-------------|
| `hello_ml.txt` | Course intro file with greetings from each team member |
| `README.md` | This file |

## Workflow Used

1. Created the repository with a README
2. Added `hello_ml.txt` with the course opening line
3. Cloned the repository locally
4. Created a feature branch to work safely
5. Added a greeting line and committed the change
6. Pushed the branch and opened a pull request
7. Merged the pull request into `main`
